# Tic Tac Toe

A single-page Next.js app for two-player tic-tac-toe with a persistent scoreboard.

## Features

- 3x3 board for Player X and Player O
- Win, draw, and turn status
- Score tracking for X wins, O wins, and draws
- Scores persist in `localStorage`
- New round and reset scores

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
